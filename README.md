Refactorización Semántica HTML5

Se reemplazaron las estructuras basadas en div por etiquetas semánticas para mejorar la estructura y el SEO del sitio web, se usó header para cabecera de página, h1 para representar encabezados mayores, nac como identificación de bloque de enlaces, main para definir bloque principal, article para delimitar otra sección independiente, aside para info complementaria, section para agrupación de distintos bloques independientes, footer para info de cierre.

Etiquetas usadas: header, nav, main, article, aside, section  y footer.

Estructura jerárquica de encabezados: Se implementó h1 para el título principal del sitio, h2 para los artículos y h3 para los bloques dentro de la barra lateral.
